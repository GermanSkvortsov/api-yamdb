YaMDb собирает отзывы пользователей на произведения. Произведения делятся на категории: "Книги", "Фильмы", "Музыка". Пользователи оставляют текстовые отзывы и ставят оценку от 1 до 10, на основе которых формируется рейтинг произведений.

## Описание проекта

Проект YaMDb — это платформа для сбора отзывов на различные произведения. API позволяет пользователям регистрироваться, оставлять отзывы, ставить оценки и комментировать отзывы других пользователей.

**Ключевые возможности:**
- Регистрация и аутентификация пользователей по JWT
- Управление произведениями, категориями и жанрами (только для администраторов)
- Создание и редактирование отзывов с оценкой от 1 до 10
- Комментирование отзывов
- Автоматический расчет рейтинга произведений на основе отзывов

## Пользовательские роли

| Роль | Права |
|------|-------|
| **Аноним** | Просмотр описаний произведений, чтение отзывов и комментариев |
| **Аутентифицированный пользователь (user)** | Права анонима + публикация отзывов, оценка произведений, комментирование, редактирование и удаление своих отзывов и комментариев |
| **Модератор (moderator)** | Права user + удаление и редактирование любых отзывов и комментариев |
| **Администратор (admin)** | Полные права на управление всем контентом. Может создавать и удалять произведения, категории и жанры, назначать роли пользователям |
| **Суперпользователь Django** | Обладает правами администратора |

## API ресурсы

| Ресурс | Эндпоинт | Описание |
|--------|----------|----------|
| Auth | `/api/v1/auth/signup/` | Регистрация пользователей |

| Comments | `/api/v1/titles/{title_id}/reviews/{review_id}/comments/` | Комментарии |

## Установка и запуск

### Предварительные требования
- Python 3.12 или выше
- Git

### Инструкция по установке

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/GermanSkvortsov/api-yamdb.git
   cd api-yamdb
   ```
2. **Создайте и активируйте виртуальное окружение**

```bash
python -m venv venv
```
```bash
source venv/Scripts/activate
```
*для Windows*
```bash
source venv/bin/activate
```
*для Linux/macOS*

3. **Установите зависимости**

```bash
pip install -r requirements.txt
```
4. **Выполните миграции**

```bash
cd api_yamdb
python manage.py migrate
```
5. **Загрузите тестовые данные (опционально)**

```bash
python manage.py import_csv
```
6. **Запустите сервер разработки**

```bash
python manage.py runserver
```
Сервер будет доступен по адресу ```bash http://127.0.0.1:8000/```.

## Работа с Postman-коллекцией

### Подготовка данных
```bash
cd postman_collection
bash set_up_data.sh
cd ..
```
### Запуск коллекции
1. Импортируйте файл Ymdb-collection.postman_collection.json в Postman

2. Запустите запросы из папки registration // No Auth/get_confirmatior_codes

3. Сохраните полученные коды в переменные коллекции:

| Переменная | Email |
|------------|-------|
| `userConfirmationCode` | user@no-admin.ru |
| `moderatorConfirmationCode` | moderator@admin.ru |
| `adminConfirmationCode` | admin-user@admin.ru |
| `superuserConfirmationCode` | superuser@admin.ru |

4. Запустите коллекцию целиком
